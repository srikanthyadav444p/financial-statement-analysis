# Financial Statement Analysis

Master's-level course resources for learning to read, analyse and interpret corporate financial statements.

## Purpose

This repository brings together the learning material for a Financial Statement Analysis course in one place. Students can study chapter by chapter, practise what they have learned and test their understanding.

## What's Inside

- **Ebooks:** Chapter-wise learning material covering the course syllabus.
- **Practice Questions:** Exercises for each chapter to reinforce concepts.
- **Excel Workbooks:** Worked models with simulations to explore how changes in inputs affect ratios and conclusions.
- **PowerPoint Presentations:** Chapter-wise slide decks for classroom use and revision.

## Who It Is For

Master's students in finance, accounting and management, and instructors looking for structured course material.

## How to Use

1. Browse the repository on GitHub, or download it using **Code → Download ZIP**.
2. Read each chapter's ebook alongside its presentation.
3. Attempt the practice questions, then use the Excel workbooks to experiment with the numbers.
